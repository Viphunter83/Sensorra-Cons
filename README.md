# SENSORRA AI (Sensorra Cons)

**Neural Operating System for Real Estate Assets**

Sensorra AI is the "No-BIM" & "AI-First" ecosystem for managing real estate assets. It acts as an Intelligent Digital Twin that parses standard PDF blueprints, ensures compliance with local building codes (Dubai), audits tenders, and enhances asset liquidity.

## Documentation

*   [**White Paper & Concept**](./docs/whitepaper.md): Detailed explanation of the philosophy, business logic, and lifecycle stages.
*   [**Project Status**](./task.md): Current tasks and progress.

## Tech Stack

*   **Core**: Next.js 15 (React)
*   **Database**: Supabase (PostgreSQL + pgvector)
*   **AI**: GPT-4o / Claude 3.5 Sonnet + RAG
*   **Visualization**: React Three Fiber & Google Photorealistic 3D Tiles
